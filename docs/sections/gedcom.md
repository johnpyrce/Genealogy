# Download family-tree data

[GEDCOM](https://gedcom.io/) is a file format for exchanging family-tree information. Download the `.ged` file below to import this tree into compatible genealogy software, such as Ancestry.com, FamilySearch.org, Gramps, Ancestris, or any other service that supports GEDCOM imports.

For a readable outline that does not require genealogy software, use the text family tree. Both downloads reflect the information and uncertainties recorded in this collection.
