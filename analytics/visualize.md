# Visualization rules

## All Charts

- Brushing a marker should label it with identifying information, including the X and Y axis values.
- Show a brush up while the mouse is hovered on a marker.  When it leaves, remove the brush up.
- Numeric axis labels always have the same precision.  Prefer integers and even numbers.  Use the minimum precision.
- Charts that fill a page should expand with the window to fill the space.  They should not have a fixed maximum size.
- A legend is always selectable to turn that data on or off. 

## Line Charts

- If time is on the X axis, plot time as a continuous value rather than as a category.
- If time is on the X axis, put a light wash in the chart background for alternating blocks based on the labelling on the X axis.
- Put the category for a chart line as a label on the first leftmost point.  This provides an in-chart definition
of the line.
- If a time axis has multiple years, abbreviate the X axis label to the year only.
